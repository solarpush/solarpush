### Products & Open Source

* **[region-to-share](https://github.com/solarpush/region-to-share)** - Native screen region capture & sharing tool for video calls (Meet, Teams, Discord). Built in Rust with egui, supporting Wayland (via XDG Desktop Portal) and X11 with low CPU overhead. Available on [Snapcraft](https://snapcraft.io/region-to-share).
* **[fX](https://github.com/solarpush/fX)** - High-performance Factur-X / ZUGFeRD / EN16931 compliant PDF/A-3 generator built with Go and Typst (~165 PDF/s), designed as a drop-in microservice for ERPs (Dolibarr, Invoice Ninja).
* **[firestore-repo-service (FRS)](https://www.npmjs.com/package/@lpdjs/firestore-repo-service)** - Type-safe Firestore ORM & repository layer for TypeScript / Node.js. Features auto-generated repositories, relations with typed select, deep pagination, batch/bulk transactions, and aggregations.
